Java 8: Streams & Functional ProgrammingThe most common coding tasks involve processing collections efficiently
.Find Duplicate Elements: Given a list of integers, find all duplicate values.Approach: Use Collectors.groupingBy with Collectors.counting() and filter for counts > 1
.Highest/Nth Highest Number: Find the second or nth highest number in a list.Approach: Use .stream().sorted(Comparator.reverseOrder()).skip(n-1).findFirst()
.Separate Odd and Even Numbers: Partition a list into two groups based on whether they are even or odd.Approach: Use Collectors.partitioningBy(n -> n % 2 == 0)
.Frequency of Characters: Count the occurrence of each character in a given string.Approach: Convert the string to a stream of characters and use groupingBy with counting()

.Switch Expressions: Convert a traditional switch statement into an expression.Java 17 style: Use the arrow syntax (->) and the yield keyword for returning values, which eliminates the need for break statements
